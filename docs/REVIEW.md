# Xray 项目检查记录

检查日期：2026-10-19。基线：v0.1.11。修复所属版本见[更新记录](../CHANGELOG.md)。

检查范围：安装入口、主菜单、节点预检与导出、服务事务、核心与管理脚本更新、备份恢复、防火墙与 BBR。Logo 复用 sing-box 项目的六行 SKYBYTE 字形，名称与功能说明使用 Xray 项目内容；沿用终端颜色和 `NO_COLOR` 设置。

## 已复现并修复

| 优先级 | 问题与复现条件 | 修改后的行为 |
| --- | --- | --- |
| 高 | 使用安装入口重新安装时，已有更高版本的 `manager.sh` 仍会被较旧脚本覆盖。 | 新安装入口核对自身与主脚本版本；拒绝降级及无法识别的已安装版本，拒绝前保留脚本与快捷命令。相同版本允许重装。已发布的旧安装入口无法随本次修改追溯更新，请使用最新入口或菜单 13。 |
| 中 | 已安装某协议，或另一协议的已停止节点占用同一托管端口时，预检仍会通过，直到目标探测、核心准备之后才拒绝安装。 | 将协议与托管端口检查提前到只读预检，保留实际端口占用检查；首次安装到不存在或空目录时不创建文件。正式配置阶段继续重复检查，防止期间状态变化。 |
| 中 | 仅安装管理器、尚未创建节点时，卸载会尝试停止不存在的服务，并假定 `state.json` 已存在。 | 仅在存在托管服务单元时执行停止与禁用；允许空节点状态卸载，仍先备份并保留未知文件。已有服务停止失败时仍中止卸载。 |

## 后续优化建议

1. **优先：增加节点诊断入口。** 将服务状态、实际 TCP 监听、客户端地址/监听地址、当前防火墙及放行操作入口放在一起；安装或修改端口后提示该节点的实际端口。需要区分本机配置通过、本机监听、主机防火墙和服务商/CDN 连通性，不仅输出“配置通过”。涉及添加放行规则时仍应明确确认，避免无提示改变防火墙。
2. **已完成（v0.1.14）：启动状态概览。** 主菜单显示本机服务器资源、实际核心版本、服务/自启、节点端口、BBR 与 WARP/防火墙/Fail2ban/二维码工具状态；查询本机且有超时，失败不阻止菜单。不展示凭据，不将配置存在等同连通。WARP 分流与 Netflix/Disney+/ChatGPT/Gemini 对比入口为菜单 14。
3. **其次：显示托管 TLS 证书剩余有效期。** 证书目前保存私密副本，外部续期后仍需手动重新导入；在状态页突出过期或即将过期，可提前发现 XHTTP/TLS 故障。自动签发与续期属于后续独立功能。
4. **验收补充：建立真实 VPS 检查清单。** 包括 systemd 开机自启、IPv4/IPv6 监听、UFW/Fail2ban、服务商安全组、CDN 与真实客户端导入。现有 CI 的真实代理连接、发行版测试和独立网络命名空间防火墙检查不能替代这些外部环境验收。

## 验证范围

本轮增加覆盖上述三个问题的回归检查；Logo 直接比对 sing-box 原字形，并核对中英文主菜单及无颜色输出。完整测试继续使用经过验证的官方 Xray 核心。服务失败场景通过隔离的 systemctl 模拟器检查，未连接或修改用户 VPS。
